# 📌 Desenvolvimento de Sistemas

Este repositório contém projetos e códigos desenvolvidos durante os estudos de Desenvolvimento de Sistemas.

## 📁 Estrutura do Projeto

- `src/` → Código-fonte da aplicação  
- `.gitignore` → Arquivos ignorados pelo Git  
- `.project` → Configurações do projeto  
- `build.fxbuild` → Configuração de build (JavaFX)  

## 🚀 Tecnologias Utilizadas

- Java  
- JavaFX  
- Git e GitHub  

## 💡 Objetivo

Este projeto tem como objetivo praticar e demonstrar conhecimentos em:
- Programação em Java
- Desenvolvimento de interfaces gráficas (JavaFX)
- Organização de projetos
- Versionamento com Git
